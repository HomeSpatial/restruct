# Security and private data

Supported release line: 0.7.x. Use the newest patch release in that line.

The viewer binds to localhost by default and should be used for local review.
Runtime configurations can launch user-selected Python and Blender executables;
only use configurations and Blender projects you trust.

Do not put credentials, private photographs, camera trajectories, home layouts
or access tokens in public issues or attachments. Use synthetic or redacted
reproductions. Report vulnerabilities through the hosting service's private
vulnerability reporting feature when the public repository enables it. If no
private channel is available, open an issue requesting a private contact without
including vulnerability details or private data.

Maintainers: enable private vulnerability reporting on the public host before
publication. No public security email address is configured in this source
candidate.
