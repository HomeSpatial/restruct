# 材质、Agent 编辑与导出

## 默认外观流程

整屋重建的默认交付包含外观。局部任务按原范围执行，不重新跑整屋；以下步骤不改写已接受的几何基线。

1. **登记覆盖并取色。** 在 `STATE.md` 列各层地面、墙面和主要家具的大面，绑定对象 ID、material_id、材料类别和证据路径。同材料可共用一项，列清覆盖区域。逐区运行 `appearance`，实际查看照片和分区图；仅采用 `reliability.usable: true` 的颜色，并核对 warnings。低可靠时换白参考／范围重查；仍无可靠观测则写明有证据支持的近似或阻塞，不能把默认 RGB 当作实测色。
2. **生成并赋用 PBR。** 用 `make_texture` 生成颜色、粗糙度、法线，并将返回的 material 字段真正赋给覆盖对象。保存材料类别、采用色来源、尺寸参数、seed、纹理路径和米制 UV；方向和尺度须对应照片。玻璃、屏幕和均匀金属等不需要纹理的材质，逐 ID 记录原因。未知材料可用保守近似，但需标明推断。
3. **看同视角效果。** 固定相机与输出设置，对照实拍及渲染检查材料分界、板条／砖缝、木纹方向、尺度和亮度。没有照片时明确不能完成的对照，不将推断写成已标定。纯外观修改另验几何保持。
4. **检查实际导出。** 用 startup 的 `check_materials_prefix` 追加最终 `model.glb --out 新目录`；旧 startup 使用 `restruct check-materials model.glb --root NAME=PATH --out 新目录`，传入模型所需的全部素材根。存在纯色例外时加 `--exceptions material-exceptions.json`，文件为 `{"glass": "照片确认透明玻璃，以 alpha 和粗糙度表达"}` 这样的逐材质说明。核对退出码、`passed`、GLB 哈希、失败部件和 `source_pixels_checked`，不得仅以图像总数验收。检查不通过，修复后重新导出和复测。
5. **重开并交付。** 保存后重开 `.blend`、重建并另行导出，再跑同一材质检查；保留原有的对象／坐标／几何往返检查。实际查看导出的模型，确认查看器保留颜色、粗糙度、法线、透明度。将通过报告和截图关联到当前 GLB 哈希，再更新 STATE。

工具检查覆盖每个导出 primitive 的三类贴图引用、图片内嵌与解码、有限且非退化的 UV、参数中的米制映射；提供 roots 时还逐像素比较源图，粗糙度比较 GLB 的 G 通道。它不判断取色是否可靠、纹理尺度是否符合实物或视觉近似是否可接受，这些由覆盖表和实际照片复核证明。无法完成的步骤保持阻塞或待做，不能以“模型已导出”关闭。

## 材质边界

根据照片识别木地板／瓷砖、墙漆等真实区域，分界应定义在稳定的表面坐标或工作世界坐标。用 `appearance` 证据查询逐个处理每层地面、各面墙和主要家具的大面：它给出材料分区、各区颜色和区间分界线段。分界清楚、长度足够且照片确认的，在该线处切开表面（地面 surface 拆成两个共享边界的对象，或按材质槽切面），各自赋予材质；面积很小的分区先看照片，常是地垫、阴影或家具底部。基础色取该区 `colour_srgb_255`，同一材料跨房间统一用一种材质；粗糙度、木纹和砖缝按照片近似，并标为推断。按旧三角形中心直接分配两种颜色会让跨界大三角形形成斜边。

- 只需改变外观时，连续 UV 纹理／遮罩可表达分区并保持几何不变。
- 需要可独立编辑的材质槽时，先在真实分界处切开目标面，再分配材质。水密外壳按对象拆分时，沿相邻共享边传播新增切点，避免 T 接缝；无须用同一平面切遍整栋建筑。全场切割可能产生细碎退化面。

地面适合世界平面 UV；竖墙使用墙面二维坐标。检查竖直面是否因沿 XY 投影而 UV 退化。

## 纹理

纯色块看起来不像真实材料。扫描照片分辨率低、地面杂物多，不宜直接投影成贴图；用 `make_texture` 按材料类别生成程序化 PBR 贴图：木地板、瓷砖、木饰面、布艺、皮革、石材台面、墙漆各用对应类别。颜色用 `appearance` 区色，尺寸参数（板宽和板长、错缝、砖尺寸、缝宽、缝色）从照片量出并写进来源说明；木纹方向和地板条走向按照片设置。家具和楼梯用 `uv_box_m`，单一平面的地面或墙面可用 `uv_work`。玻璃、屏幕、金属不加木纹类图案，保留 alpha／金属度。程序化纹理是外观近似，不能称为实测材料参数；渲染后与同视角照片对照板条走向、砖缝间距和明暗对比。

核对颜色空间：用户输入 sRGB 颜色到 Blender shader 的线性值要正确转换；颜色图片用 sRGB，粗糙度与法线作数据纹理。glTF 合并纹理的粗糙度在 G、金属度在 B，法线方向约定也应核实。预览器必须保留导入的贴图和 PBR 参数，避免用统一粗糙度覆盖真实材质。导出后检查实际图片、通道和引用，不能只看 Blender 中的 shader。

## Agent 接口优先

先发现当前插件的 `describe()`／README 和运行场景。稳定 ID 定位目标，独立的核心函数供 Python、JSON 操作符与面板调用；批量操作不依赖鼠标选中状态。面板演示则明确设置 active object 与 selection 两者。

HomeSpatial 的 `api.dispatch({op,args})` 返回 `ok/data` 或错误；`validate/validate_scene` 还需检查 `data.passed`，不能把调用成功当作模型检查通过。批处理失败会停止，但此前修改没有自动回滚。

已有 HomeSpatial 插件时，使用其接口，不复制另一个生成器或后台服务。离线检查可用独立 Blender 后台进程；用户要求实际演示时，操作真实窗口并核对界面。不要为只读分析安装插件或改正在使用的工程；用户已授权安装／演示则继续完成相应操作。

## 按契约区分尺寸和坐标

先读取文档 kind/schema_version 或 inspect_scene 返回的内嵌模型，不依据一个版本数字猜轴向。现代输入的 scene/frames/alignment 仍用 v1 数据契约，各来源按其声明转换；这不等于下面的旧 Blender bundle。

- **当前 model v2**：`kind:model, schema_version:2`，参数和工作坐标为右手 Z-up 米制；局部 box 尺寸沿父局部轴。使用 create_scene/update_scene/capture_transforms/rebuild_scene，保存 `.blend + .scene.json + .project.json`；export_scene 输出标准 glTF Y-up，核对 `T_work_from_gltf` 和内嵌参数。网格手改不自动反推参数。准确签名和矩阵见仓库 `docs/scene-model.md`。
- **旧 Blender v1 bundle**：`structure.json + model-manifest.json + structured.glb`，仅在元数据明确声明 `ROS z-up, original origin`、米制时使用 open_project 和旧网格编辑接口；按 aligned_frame_from_ros 导入，旧 export_glb 恢复原 ROS 坐标。set_dimensions 使用对齐世界轴包围盒，`null` 保留轴，MIN/CENTER/MAX 指固定端；它不联动墙体，也不用于 model v2 参数编辑。旧保存只有 .blend/.project.json，不回写 structure.json。
- **v1 契约的 kind:model JSON**：也是工作 Z-up 表达，不等于旧 ROS bundle；当前 restruct build 只接收 model v2，需要显式迁移才能建模，不猜测旧生成器参数。

对一般导入器，若其已应用轴转换 C，而源到工作变换为 A，补偿为 `A @ inverse(C)`；导出按所属契约反变换。`export_yup=False` 仅是旧 ROS 导出的特殊约定，不能用于 model v2 或普通 glTF。

旧网格做世界非均匀缩放可能含 shear，简单分解 location/rotation/scale 会丢失它。需要此类编辑时可复制网格，用 `M_world^-1 @ S_world @ M_world` 烘焙，并检查固定端及非目标对象。v2 使用支持的参数更新或刚体/正向 box 缩放回写。零厚度表面不能当实体厚度缩放。

## 保存与导出边界

- 保存所属模式的编辑真源和来源／操作记录：v2 使用内嵌参数及 .scene.json；旧 bundle 使用已编辑 .blend 及日志。原始生成器不会自动吸收网格修改。
- 将参考扫描放入独立、锁定且排除导出的集合。实际导出明确限制当前项目、当前场景和对象集合，再读取文件核对 ID 清单，防止默认 Cube 或其他 Scene 混入。
- 保存／导出使用独立路径。原输入扫描和模型不可被误当作输出覆盖；重复输出遵循调用者明确的覆盖选择。
- 验证保存后可重开、图片是否内嵌、照片证据路径是否仍可用。懒加载图片的 `has_data=False` 不一定丢失；尝试实际解码并检查尺寸／像素，真正缺失仍应报错。
- 导出的 GLB 用独立读取器复核世界顶点、对象数量、材质分区和贴图；外壳按位置重组后验证闭合。往返误差容限依据单位、浮点精度与用途设定，不使用案例数字作固定门槛。
