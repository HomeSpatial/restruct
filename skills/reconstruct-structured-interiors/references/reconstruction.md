# 从证据到可编辑结构

## 坐标和照片

先确认网格场景节点变换已应用，不能只读取 geometry 的局部顶点。用已知墙角、门边、楼梯或家具验证尺度与坐标，而不只比较整体包围盒。

若原地图到工作坐标的变换为 A、相机位姿为原地图中的 `T_world_from_camera`，则工作坐标相机位姿为 `A @ T_world_from_camera`。像素射线方向由旋转部分乘 `inverse(K) @ [u,v,1]` 得到，原点为变换后的相机中心。先核实光学轴和位姿方向；照片若经过裁剪、缩放或去畸变，K 必须与当前图像匹配。

照片选取同时考虑对象声明来源、视锥投影和遮挡可见性；画面包含对象不代表其关键表面可见。像素射线可能穿过玻璃、扫描洞或命中背景，检查落点、法线与相邻视角后再用于拟合。颜色判断结合多帧，避免把阴影当成材质分界。

核对 RGB 来源是实拍、扫描渲染还是生成图，记录在场景报告中。扫描渲染图可用于识别局部结构，但与同一扫描的射线/拟合不是相互独立的测量；不要据此宣称独立空间精度通过。拟合前实际查看更紧的裁图，桌面上的鼠标垫、物品或薄板可能与目标平面只差几毫米，主平面支持率高也不能代替语义核查。

## 墙、地板、天花与开口

- 用连续平面支持估计墙线与标高，用照片和截面确认轮廓、门窗与楼梯井。不要把每个扫描孔都保留成真实开口，也不要用填洞覆盖真实通道。
- 在细化家具前，查看一次完整高度的建筑模型与关键截面。相邻天花或墙顶标高不同时，检查连接它们的立面、梁侧或收口；结合扫描和照片区分真实开口、扫描边界与漏建面。普通结构化也需表达可确认的连接，是否要求整个外壳水密仍由任务决定。
- 优先建立相邻表面共享的边和拐角。各平面独立投影、简化再拼接，容易在墙脚、楼板边、平台交接处产生裂缝或上下层误命中。
- 地板高度与覆盖范围分别建模和检查。桌面、柜面、床面也可能水平，不能归为地板；漏掉桌面往往来自“只提取地板／天花水平面”的分类遗漏。
- 有厚度的表面同时检查参数面、整圈绕序法向及实际导出面。厚度沿法向从 offset 到 offset+thickness；用截面或射线确认它位于测量面的正确一侧。节点标高正确而导出面相差一个板厚时，先定位法向／挤出实现，避免改节点高度补偿工具错误。
- 家具使用独立参数对象：桌板与腿、柜体与门、沙发座垫与扶手、床架与床垫。保留桌下空间等有意义空隙。遮挡部件用简单近似并标注来源，不将衣物、反射碎片固化为结构。
- 柜体按照片表达正面：有门的柜子建出门板（按照片的门数和分缝，门板与柜体分开、留出缝），开放格保留开口；不要用一块整板代替一排门。电视、显示器等嵌在柜体凹槽里时，建出柜体、凹槽、饰边和下方的柜／格，而不是建成平墙加挂件；判断依据是照片中凹槽的侧壁、饰边和进深。
- 护栏按照片区分材料和构件：玻璃栏板用透明玻璃材质（alpha 小于 1），其上的扶手、立柱、底座另建实体；不要把玻璃建成不透明墙板，也不要漏掉扶手。
- 深色、黑色或反光的物体（冰箱、电视、玻璃门、黑色家电）在 DA3 扫描里常是空洞或错位面，检测器也可能漏检。这类对象用照片定位：在多个视角上用像素射线打到它的边缘或相邻的可靠表面（地面、侧板、吊柜），不要用空洞旁边的扫描或剩余空间推断位置。
- 墙面颜色按照片逐段确认：同一面墙可能分段刷不同颜色或贴砖（灰墙与厨房白砖、背景墙），对整面墙做 `appearance`，中性色相邻时加 `lightness_weight`，不要只量一小块就给整面墙定色。

## 家具候选到部件模型

检测框与三维包围框用于定位候选。先用可见照片和局部扫描确认主要对象的数量、占地轮廓、方向及要测的表面，再套用部件模板；特别检查多件合框、重复框、转角家具和桌面物品。一个来源引用只证明追溯关系，关键尺寸仍需落点或截面支持。

误差统计按语义表面解释：沙发座面、靠背、扶手和柜面分别检查，目标部件射线与全场景首次命中并看。若新旧命中了不同部件，先核对遮挡与范围，再决定改尺寸还是改结构。证据支持的近似保留为推断，避免把检测框直接宣布为已校准模型。

### 外轮廓和内部部件分别校准

对正在重建或修正的主要对象，先取得控制可见几何的证据：水平表面的标高与平面内边界、立面的朝向与进深、重复部件各自的位置。把落点／截面结果关联到实际参数；来源照片引用或整个家具的检测框不能代替这一步。已测参数先保留，增加细节时不要让模板默认值覆盖它们。

- **平面朝向**：家具不默认与墙平行。显示器、电视、椅子、餐桌、落地扇等可自由摆放的对象，朝向和位置一样是待测参数；风扇、台灯、椅子这类有明确正面的小件，按照片确认正面朝哪里（扇面、灯罩开口、座椅前沿），扫描支持少时以照片为准。检测框的 `R_work_from_object` 给出偏航先验（尺寸与中心仍不是测量），用正面平面拟合、桌面外沿的像素射线或俯视截面核实后写入 `yaw_degrees`；整组摆放就转父 assembly，单件转动只转该部件。核实结果是正交的，才对齐到墙轴。
- **座面、桌面等小支撑面**：分别检查面内标高和跨边缘的命中切换，并保留边缘外一圈背景。相邻两件家具可共用构造方法，但位置、尺寸、朝向须分别核实。座面可能有弧度、孔口或倾斜；照片支持时表达这些结构，扫描缺口则保留不确定性。厘米级横移会使射线从座面落到地板，仅看已命中座面的误差会漏掉它。
- **连续柜台和不同标高的相邻面**：先分清每段台面、水槽边、盆底、吧台和杂物，再拟合各自可见支持。若拟合区域跨越多个高度，检查支持点分布、法向和截面；一个倾斜主平面可能只是混合表面的折中。联合核对外沿、转角、相邻段接缝及真实开孔，不能只校准高度或只测其中一段。高低天花交界同样需要检查平面内分界和连接面。
- **书架等重复板件**：分别核实侧板外沿、前沿／背面进深与每层板的标高，不把外框高度等分自动当成已测层间距。用正面加侧向或俯视证据区分层板、背板、墙和架上杂物；保留有证据的空格。照片未完整显示边界时换视角，缺失处才用标明的不确定近似。

对相邻独立对象，分别贴合扫描后还要检查相对关系。移动支撑板、改变凳腿外张或调整柜体进深时，用低角度和截面核对接触、间隙及实体穿插；投影或包围盒重叠不足以证明实体冲突。发生冲突时，重新辨认来源表面、局部凹槽和厚度假设，依据证据修正相关参数，避免为了消除相交任意平移整个物体或掏空支撑。

## 来源到模型的覆盖清单

在任务 `STATE.md` 里维护一张短表，不另建平行记录。整屋任务先按来源中的空间区域观察建筑、主体和可辨认附属结构，再映射到模型；已有模型的局部任务只记录受改范围及相邻依赖。感知候选和模型对象清单可辅助定位，不能单独作为完整性清单。

首版建成后运行 `restruct residuals`，它把模型解释不了的扫描表面聚成簇，按面积列出位置、朝向、到模型的距离、最近对象和能看到它的照片，并生成每簇一格的照片拼图（红点为未解释表面）。逐格查看全部簇，不只看前几名：`unmodelled_region`（远离模型）常是漏建的搁板、壁架、隔断；`missing_surface_near_model`（贴近对象但沿法向没有模型面）是缺了一块面，如分段台面之间的转角、截短的外沿；`offset_surface` 是平行偏移的面。同一报告的 `excess` 部分列出相机看穿的模型面（`excess-*.png`，红点为模型面所在位置），对应部件偏大、外凸、错位，或本该敞开的地方建成了实体。报告的 `plan_fit.shifted` 列出台面、座面、层板等朝上的面：在平面上平移若干厘米后与同高度扫描面重合得更好，即整件或部件在平面内错位，修正时测量外沿并移动或改尺寸。`facing_fit.turned` 列出平面朝向与附近竖直扫描面或重叠检测框不一致的对象（按 90° 取模比较，附转角、扫描支持占比和检测框 ID），逐项用照片和正面拟合确认后改 yaw；圆形或无明显正面的对象可注明不适用。excess 只看得到错位产生的窄边，不要把它当成扫描洞放过，也不等于要删掉体积。两类簇都按面积排序，逐簇处理：要么补成清单行／问题，要么注明属于杂物、衣物、扫描伪面、玻璃或屏幕造成的扫描空洞，或有意的简化，并引用该拼图或裁图。它只覆盖扫描到的表面，扫描缺口仍需照片巡视。

| 来源区域／观察项 | 来源证据及类型 | 对应模型 ID 或未建 | 待核实特征与检查覆盖 | 当前状态／问题 ID |
|---|---|---|---|---|
| 由照片或扫描实际发现的对象、开口或连接 | 原图帧／截面／扫描查询；实拍或扫描渲染 | 尚无对象也保留该行 | 外沿、标高、空隙或相邻关系；能看到该特征的视角和查询 | 待查／有问题／已核实／有理由省略；链接证据 |

检查覆盖要写明查询方向、起点相对表面的位置、边缘外背景以及相关可见视角；采样尺度按特征和扫描分辨率选择。整屋俯视图或一个对象名称不表示全部边缘和内部部件已经检查。来源不足保留待查，并写缺少哪种观察；建模时新发现的对象或关系补回此表。

例如来源可见一块悬空薄板，而模型只有地面：清单仍应记录薄板“未建”。从薄板下方朝下的零误差只能核实地面；应补能碰到薄板的查询，在修改前后两版重放，并保留原域。这是按来源发现盲区的方法，不要求每个场景使用同一高度或方向。

## 首版后的修正循环

整屋首版是可检查的起点。实际使用沿用同一输入、感知结果和参数工程，按问题局部迭代；只有发现输入或感知本身有误才重跑对应阶段。已校准的对象和建筑边界作为下一轮约束保留。

首轮按覆盖清单检查建筑标高、完整高度连接和通道，再逐项核对主要家具的数量、轮廓、方向、支撑面及可见空隙。按以下顺序处理，前一级仍有已确认未关闭项时不进入后一级：

1. 建筑：墙地顶缺失、高差处连接面、`check-geometry` 报出的外壳漏缝、被封住的通道。
2. 主体家具：residuals 中远离模型的大簇（漏建）、数量／方向错误、主体外轮廓明显偏移。
3. 对象关系：不同对象的实体穿插、同向共面重叠（不论拍摄相机能否看到）。
4. 局部精度：支撑面、边缘、层板等的残差。
5. 装饰与小件：植物、灯具、挂画、自行车等。用简单几何体表达，单件不投入多轮。

将发现写进现有报告或任务记录的简短问题表：问题 ID、对象／位置、失败证据、拟修改参数、复测方法、当前状态及对应模型版本／哈希。量化异常要落回代表性命中点和来源照片，避免凭总分同时修改整屋。后续出现的缺失、覆盖变化和关系问题持续补入，不只更新首轮已有条目。

每轮围绕一个原因或一组关联对象进行：

1. **取证和定位**：明确实际边缘／表面、相邻关系以及哪些已测参数要保留。若参数与导出不一致，先排查工具；场景任务中发现通用缺陷时保留最小复现，按当前授权另行修复工具。
2. **局部修改**：从上一轮保留版本修改相关参数，记录证据和推断。每轮保存可回退版本；不重新生成无关对象，也不让模板覆盖已校准值。
3. **复测和接受**：重放原局部查询，同时查看异常摘要的表面偏差、漏射、额外命中和命中对象变化，并检查邻接与固定视角；改动涉及接触或拼接时对新版运行 `check-geometry`，确认没有新的穿插或共面重叠；新增诊断查询在前后两版运行、与原域分别报告。候选满足本次修正目的且相关回归有依据后才成为下一轮基线。出现无依据的明显退化，撤回该项或继续定位；平均误差下降不能抵消缺面、封通道或实体穿插。
4. **选择下一项**：更新问题状态，优先处理剩余建筑连接、缺失主体和大范围边界偏差。新增结构后再看一次整体与完整高度，防止局部视角漏掉关系错误。

### 按证据关闭问题

问题状态按以下依据更新；报告字段仍用现有表格，无需额外状态系统。

| 状态 | 所需依据 |
|---|---|
| 待查／待补证据 | 哪个特征尚未核实，缺少的视角、截面或采样；不能计为通过 |
| 已确认待修 | 来源支持的失败位置、命中／覆盖差异及影响 |
| 已修复 | 原失败位置在最终相关版本上的复测结果和证据路径；同时交代覆盖及相邻关系回归 |
| 保留近似／有理由省略 | 具体部件或表面、来源限制、可观察影响，以及为何符合用户目标；杂物或遮挡须有局部证据 |

“均值改善”“已看渲染”“导出通过”只支持各自观察，不能单独关闭结构问题。表面仍有明显偏差时，先解释代表点和覆盖变化，再决定继续修正或保留近似。若最终版本再次修改了该对象或相邻依赖，原关闭证据需要复测或给出相关几何未变的依据。停止尝试时保留未解决状态，不把停止原因改写成已修复。

交付前暂时放下已有问题顺序，对最终版本重新运行 `residuals` 与 `check-geometry`，并从来源区域再巡视一次，检查是否仍有“来源可见、模型无对应物”或未检查特征，并核对问题表的最终证据。完成条件仍由用户目标决定：范围内有充分证据的主要结构错误已处理，相关查询和视觉回归通过，剩余近似有明确影响。证据不足时记录需要的观察；同一方向连续几轮没有可度量进展时停止该方向，汇报原因与替代路径。用户限定时间或轮数时按预算交付当前状态，不预设所有场景必须经过相同轮数。

日常使用时，同一 Agent 可以交替建模与审查；用户授权独立审查时，将问题位置、命中对象和证据交给建模 Agent，再由其复核修正。保持一个参数写入者。只有独立能力测试明确要求冻结时，才把审查发现留在评估报告；继续修复须保存为单独阶段，不覆盖冻结结果。

## 楼梯校准

先检查代理生成器的方向假设。对整段踏步中心做 PCA 的上升方向不一定垂直实际侧墙，继承该方向会让所有前沿一起倾斜。

1. 分离直跑段、转角踏步、上下平台和侧墙。墙向应由可靠墙面支持决定；转角踏步不套用直段矩形。每一级的平面形状都要用照片确认：起步和收头处常有扇形、加宽或斜边踏步，扫描高度图给出候选轮廓，但扫描在踏步前沿会有涂抹和偏差，照片中的踢面线、前沿走向和级数是最终依据。逐级与同视角照片对照（含最下两级和最上两级），形状、级数或走向不符时按照片改。
2. 每级标高从踏面内部的连续近水平支持估计，可采用面积加权的主峰／中位数。保留支持面积和残差；玻璃旁斜坡、孤立尖峰和稀疏角落不能强行拟合成踏面起伏。
3. 前沿与立面分开核对。鼻口外伸时，立面中线位置不等于支撑切换位置。可比较跨前沿的竖直射线高度跃迁、多个立面截面和 RGB；使用连续支持而非第一个偶然命中。
4. 在有依据的直线／平面约束下拟合干净边缘，避免逐像素追随扫描锯齿。修改前沿后检查与上一阶、下一阶及转角踏步的覆盖，清理外露重叠面和闪烁。
5. 平台唇边单独检查。毫米级横向偏差可让射线跨过约一阶的高度跳变；整片填平或强制成一条直线可能改变实际支撑。

采样密度、滤波尺度、面法线和残差阈值需适配扫描分辨率与用途。案例中的厘米／毫米数值是实验参数，不能移植为任意楼梯的合格线。连续几轮没有改善同一指标时，回到来源与查询含义，不继续叠加补偿几何。

## 要求水密时

对于连通室内外壳，可先构造室内空气体积：按层高与地面轮廓并集，连接全高楼梯井，再扣除带真实开口的隔墙，最后提取朝向室内的边界。它能解决大量独立面片补缝，但不是所有项目都必须使用体积布尔。

门窗封合由所需状态决定。根据输入和交付需求确定外部门窗状态，保留实际室内门洞和楼梯井，不能默认关闭所有洞口。若需要开门状态或室外连通，应明确相应边界，而不是为通过水密测试添加假墙。

建筑外壳与家具、楼梯等独立实体分开验收；无需把所有对象布尔成一个体。保留层高、梁底、窗洞侧壁和楼梯净空。材质拆组后按几何位置重组检查闭合，UV／法线接缝会导致顶点索引断开，不能直接据此判为几何漏缝。
